# Тестирование приложения

Этот проект включает юнит-тесты на Jest и интеграционные тесты на Cypress.

## Установка зависимостей

Перед запуском тестов убедитесь, что все зависимости установлены:

```bash
npm install
```

## Jest (юнит-тесты)

### Запуск тестов

```bash
npm test
```

### Запуск в режиме наблюдения

```bash
npm run test:watch
```

### Проверка покрытия кода

```bash
npm run test:coverage
```

### Структура тестов

Юнит-тесты расположены рядом с тестируемыми файлами:

- `src/services/store.test.ts` - тесты для инициализации rootReducer
- `src/services/slices/burgerConstructorSlice.test.ts` - тесты для редьюсера конструктора бургера
- `src/services/slices/ingredientsSlice.test.ts` - тесты для редьюсера ингредиентов
- `src/services/slices/orderSlice.test.ts` - тесты для редьюсера заказов

### Что тестируется

#### rootReducer
- Правильная инициализация store
- Наличие всех необходимых редьюсеров

#### burgerConstructorSlice
- Добавление ингредиентов (булки и начинки)
- Замена булки при добавлении новой
- Удаление ингредиентов
- Перемещение ингредиентов
- Очистка конструктора

#### ingredientsSlice
- Обработка состояния `pending` (loading: true)
- Обработка состояния `fulfilled` (сохранение данных, loading: false)
- Обработка состояния `rejected` (сохранение ошибки, loading: false)

#### orderSlice
- Обработка состояний создания заказа (pending/fulfilled/rejected)
- Очистка заказа
- Последовательные сценарии создания и очистки заказов

## Cypress (интеграционные тесты)

### Запуск в интерактивном режиме

```bash
npm run cypress:open
```

### Запуск в headless режиме

```bash
npm run cypress:run
```

**Важно:** Перед запуском Cypress-тестов убедитесь, что приложение запущено на порту 4000:

```bash
npm start
```

### Структура тестов

Интеграционные тесты расположены в папке `cypress/e2e/`:

- `cypress/e2e/constructor.cy.tsx` - тесты для конструктора бургера

### Что тестируется

#### Добавление ингредиентов
- Добавление булки в конструктор
- Замена булки при добавлении новой
- Добавление начинки
- Добавление соуса
- Добавление нескольких начинок

#### Модальные окна ингредиентов
- Открытие модального окна при клике на ингредиент
- Закрытие по клику на крестик
- Закрытие по клику на оверлей
- Отображение детальной информации об ингредиенте

#### Создание заказа
- Успешное создание заказа
- Отображение правильного номера заказа
- Закрытие модального окна заказа
- Очистка конструктора после создания заказа
- Корректный подсчет общей стоимости

### Моковые данные

Моковые данные для Cypress-тестов находятся в `cypress/fixtures/`:

- `ingredients.json` - моковые данные ингредиентов
- `user.json` - моковые данные пользователя
- `order.json` - моковые данные ответа на создание заказа

Все API-запросы перехватываются и возвращают эти моковые данные.
